## 下单前必须知道的三件事

这几条都写在官网页面或被多方交叉验证过，但多数导购文章一笔带过。

1. **不可退款**。Budget KVM Sale 和 Premium KVM Sale 全系列都标注 No refund/Money back [S23][S26][S28]。年付四五十美元打水漂不致命，但机房选错的体验很差，下单前先用官网的 Looking Glass / 测试 IP 测一下你所在网络到目标机房的延迟和丢包，东京两条线路要分别测。

2. **库存是开仓式补货**。绿云的促销节奏偏「定期开仓」，Budget KVM Sale 年付 $25 起的特价经常出现，配合黑五、周年庆、节日活动，部分活动还附带三年付送双倍硬盘和流量（2026 年独立日活动就是三年付逻辑：$74/3 年常规 VPS、$168/3 年 4TB 存储机）[S1][S11][S16]。补货窗口的库存普遍紧张，比如 Premium KVM Sale 曾出现洛杉矶仅剩 1 个、阿姆斯特丹全售罄的记录 [S26]，看到合适的价格别犹豫太久。第三方优惠码页面偶尔有 30% OFF 之类的码，但有效性需要自行验证，别把它当默认预期 [S1]。

3. **同配置随机房分价**。同一个档位在东京、香港、新加坡、英国价格和流量都不同，存储类型（NVMe 还是 SSD）和 CPU（EPYC 还是 E5v4）也不同 [S1][S23][S27]。对比价格时务必看清楚机房参数，别只看数字。

## 常见问题

**绿云大内存 VPS 可以退款吗？**
Budget KVM Sale 和 Premium KVM Sale 全系列都不可退款，这是官网购物车页明确标注的条款 [S23][S26]。其他产品线的退款政策未在公开页面统一展示，下单前如有疑问直接开工单确认。

**8GB 档一年到底多少钱？**
没有固定答案。第三方口径在 $45 到 $68 之间浮动 [S1][S4][S27]，取决于机房（EPYC/NVMe 新机房偏贵）和促销批次。购物车页选好机房后显示的才是最终价。

**能不能装 Windows？**
Budget 和 Premium KVM Sale 都标配 Linux OS，官方页面写明仅支持 Linux [S23][S26]。绿云有单独的 Windows VPS 产品线，需要 Windows 的读者应该看那条线而不是本系列的促销机。

**跑什么最划算？**
8GB 内存 + 8TB 流量 + 10Gbps 端口的组合，适合 Docker 多容器、小型数据库、爬虫集群、备份归档、监控探针矩阵这类「吃内存不挑线路」的活。拿去给国内用户提供晚高峰服务是错配。
